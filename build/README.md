# Сборка .exe

PyInstaller не умеет кросс-сборку: **exe для Windows собирается на Windows**.
С macOS собрать `.exe` нельзя — ни через Wine-обвязки в CI, ни иначе, без
подводных камней с Qt-плагинами.

## На Windows

```
py -3.11 -m venv .venv
.venv\Scripts\pip install -e ".[dev]" pyinstaller
.venv\Scripts\pytest
.venv\Scripts\pyinstaller build\resolve-project-search.spec
```

Результат: `dist\ResolveProjectSearch.exe`, один файл, Python на целевой машине
не нужен.

## Проверить перед раздачей

1. Запустить exe на машине, где Python не установлен вообще.
2. Прогнать поиск по сетевой папке — самый частый реальный сценарий и самый
   вероятный источник тормозов.
3. Нажать «Стоп» в середине сканирования большой папки: окно должно
   отреагировать сразу, а не после текущего файла.
4. Открыть выгруженный CSV в Excel — кириллица должна читаться без импорта.

## Размер и антивирус

Один файл выходит примерно 45–70 МБ: это Qt, а не код приложения. Список
`excludes` в спеке убирает неиспользуемые модули Qt.

Однофайловые сборки PyInstaller регулярно ловят ложные срабатывания
SmartScreen и антивирусов, потому что распаковывают себя во временную папку при
запуске. Варианты, если это мешает:

- собрать папкой вместо одного файла (`--onedir`) — запускается быстрее и
  срабатываний меньше;
- подписать exe сертификатом code signing.

## Иконка

Положить `build\icon.ico` — спека подхватит её автоматически. Без файла сборка
проходит с иконкой по умолчанию.
